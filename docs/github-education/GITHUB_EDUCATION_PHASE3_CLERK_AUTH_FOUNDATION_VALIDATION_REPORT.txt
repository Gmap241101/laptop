Authentication Security Properties
----------------------------------
- Authorization header must be Bearer format.
- JWT algorithm must be RS256.
- Signature is verified with CLERK_JWT_KEY using Node.js built-in crypto.
- exp and nbf claims are validated with configurable 0-60 second clock skew.
- sub and sid claims are required.
- azp is checked against exact CLERK_AUTHORIZED_PARTIES when present.
- sts=pending is rejected by default.
- Raw JWT and signature are never returned by /api/auth/session.
- Authentication errors return a generic unauthorized response to clients.
