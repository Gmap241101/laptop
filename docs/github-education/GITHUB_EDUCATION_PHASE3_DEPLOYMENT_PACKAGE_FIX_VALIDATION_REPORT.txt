GitHub Education Phase 3 deployment package compatibility fix validation
Date: 2026-08-07
Baseline: rental-system-github-education-phase3-clerk-auth-foundation-20260807_deployment_package.zip

ROOT CAUSE
- The baseline package physically contained .env.example.
- package-meta/PACKAGE_FILES.txt listed .env.example as a replacement payload entry.
- deploy.ps1 v13.1 correctly rejects .env* as protected paths, so deployment stopped before completion.

FIX
- Removed .env.example from the deliverable package.
- Moved non-secret configuration examples to docs/github-education/HEROKU_CONFIG_VARS_TEMPLATE.txt.
- Removed the .gitignore exception that allowed .env.example.
- Updated tools/backend/validate-server-foundation.mjs to validate the safe config template instead.
- Added tools/deployment/validate-package-manifest.mjs.
- Added npm run package:guard.
- The package guard rejects .env*, .git, node_modules, dist, secrets/.secrets, and deploy.ps1 entries.
- .env.example is intentionally NOT added to REMOVED_FILES.txt because .env* is a protected local path and must not be mutated by the replacement package.
