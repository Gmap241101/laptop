PostgreSQL code: 22P02
Message: invalid input syntax for type json

Root cause
----------
app_runtime_metadata.value is JSONB NOT NULL, but migration 003 attempted to insert plain SQL text 'phase6'.

Correction
----------
Migration 003 now writes structured JSONB using:
jsonb_build_object('phase', 6, 'bridge', 'firebase-auth')

Rollback / retry safety
-----------------------
The migration runner starts BEGIN before migrations and issues ROLLBACK on any failure. Therefore the failed 003 transaction is expected not to be recorded in schema_migrations and its CREATE TABLE / CREATE INDEX statements are expected not to be committed. Editing the failed, unapplied 003 migration is therefore the correct retry path.
