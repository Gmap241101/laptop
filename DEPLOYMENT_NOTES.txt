사이트 관리 홈 화면 통합·배너/푸터 모달·팝업 순서 관리 배포 안내

기준 패키지
- banner_footer_carousel_ux_fix_deployment_package.zip

배포 순서
1. 배포 패키지의 src 폴더를 프로젝트 src 폴더에 반영합니다.
2. 배포 패키지의 rules/firestore.rules를 로컬·원격 프로젝트의 rules/firestore.rules에 반영합니다.
3. 이번 변경에서 Firestore Rules 내용은 기준본과 동일하므로 기존 최신 Rules가 게시되어 있다면 재게시가 필수는 아닙니다.
4. 프로젝트를 빌드하고 배포합니다.
5. 관리자 모드 > 사이트 관리에서 아래 기능을 확인합니다.

홈 화면 관리 통합
- 기존 홈 화면 기본 설정, 메인 비주얼 관리, 프로모션 배너 관리, 바로가기 배너 관리를 '홈 화면 관리' 하나로 통합했습니다.
- 홈 화면 관리 내부 탭:
  · 홈 화면 기본 설정
  · 메인 비주얼
  · 프로모션 배너
  · 바로가기 배너
- 기존 메뉴 키로 진입하면 대응하는 내부 탭으로 자동 이동합니다.

배너 편집 모달
- 메인 비주얼, 프로모션 배너, 바로가기 배너 등록·수정을 화면 중앙 모달로 표시합니다.
- 기존 이미지 표시 방식, 초점 위치, 링크 방식, 현재 탭/새 탭, 노출 기간 기능은 유지합니다.

푸터 편집 UX
- 푸터 메뉴 페이지 등록·수정을 화면 중앙 모달로 표시합니다.
- 푸터 전용 제목 표시 방식은 유지합니다.
  · 텍스트 제목
  · 이미지 제목
- 연결 입력 영역은 배너 관리와 같은 20% / 20% / 60% 구조입니다.
  · 연결 방식: 본문 직접 입력 / 외부 링크 / 링크 없음
  · 탭 열기: 현재 탭 / 새 탭
  · 연결 대상: 외부 링크 주소 또는 상태 안내
- 더 이상 링크 없음 처리를 위해 #을 입력할 필요가 없습니다.
- 기존 linkUrl 값이 #인 문서는 수정 화면에서 자동으로 '링크 없음'으로 해석합니다.

팝업 순서와 목록 개수
- 팝업 목록에 위/아래 순서 이동 버튼을 추가했습니다.
- 팝업 sortOrder는 관리자 목록과 사용자 노출 순서에 함께 적용됩니다.
- 기존 sortOrder가 없는 팝업은 생성일 기준으로 표시되며, 저장·이동·삭제 시 연속 순번으로 정규화됩니다.
- 한 번에 보기: 10개 / 30개 / 50개 / 100개
- 노출 페이지, 노출 기간, 현재 상태, 등록일 열 너비를 줄여 순서 열을 추가했습니다.

운영 확인 시나리오
1. 홈 화면 관리의 네 내부 탭을 전환합니다.
2. 각 배너 종류에서 등록·수정 모달이 화면 중앙에 표시되는지 확인합니다.
3. 푸터에서 본문 직접 입력, 외부 링크, 링크 없음 세 방식을 각각 저장합니다.
4. 외부 링크를 현재 탭과 새 탭으로 각각 열어 봅니다.
5. 기존 # 방식 푸터 문서를 수정한 뒤 링크 없음으로 저장되는지 확인합니다.
6. 팝업 12개 이상으로 위/아래 이동과 10·30·50·100개 보기를 확인합니다.
7. 사용자 화면에서 팝업이 관리자 순서대로 표시되는지 확인합니다.

변경하지 않은 범위
- 대여 신청·승인·반납 로직
- 회원가입·회원 계정·관리자 인증 로직
- Firestore 컬렉션 경로와 Rules 권한
- 팝업 등록 모달의 본문·노출 페이지·노출 기간 입력 기능
- 푸터 공통 정보 저장 기능
